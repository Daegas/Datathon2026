Modelo **XGBoost** que estima la satisfacción esperada del cliente en una escala de 1 a 10, usando datos financieros y de comportamiento como ingresos, uso de productos o actividad.

- carga el perfil del cliente 
	- Combina información de clientes, productos y transacciones
	- Analiza el contexto de sus conversaciones usando el tipo de conversación del cliente y el estilo de respuesta del asistente. 

Esa predicción se transforma en acciones concretas. El sistema sugiere productos o seguimientos que pueden mejorar la experiencia del cliente.
